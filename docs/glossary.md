# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|
| Artifact | A deployable component generated by a build process. / Компонент за внедряване, генериран от процес на изграждане. |
| Branch | A parallel version of a repository. / Паралелна версия на хранилището. |
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Commit | A saved change to the code repository. / Запазена промяна в хранилището с код. |
| Container | A packaged application with its dependencies. / Пакетирано приложение с неговите зависимости. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Merge | Combining changes from one branch into another. / Обединяване на промени от един клон в друг. |
| Pipeline | Automated steps to build, test, and deploy code. / Автоматизирани стъпки за изграждане, тестване и внедряване на код. |
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Release | A published version of the software ready for use. / Публикувана версия на софтуера, готова за употреба. |
| Rollback | Reverting to a previous version of the software. / Връщане към предишна версия на софтуера. |
| Runner | A server or agent that executes CI/CD jobs. / Сървър или агент, който изпълнява CI/CD задачи. |
| Tag | A label pointing to a specific point in Git history. / Етикет, сочещ към конкретен момент в историята на Git. |
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |

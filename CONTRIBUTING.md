# Как работим

## Имена на клонове
feat/кратко-описание за нови неща
fix/кратко-описание за поправки
docs/кратко-описание за документация

## Комити
Кратко съобщение в повелително наклонение: "Add CODEOWNERS"
Един комит = една смислена промяна

## Pull Request
Всеки PR е за една задача и започва с `Closes #номер`
Нужно е поне едно одобрение от другия човек
Не се слива собствен PR без ревю

Branching strategy: GitHub Flow, защото е проста за малък екип.
